# docs 안내 — 어떤 문서를 언제 보나요

이 문서는 깃허브 레포지터리의 `wakeup` 브랜치를 클론하여 **2차 작업(스마트 기상 시스템 고도화 및 라즈베리파이 5 연동, 배포)**을 진행하는 학생들을 위한 문서 가이드입니다.

1차 완성본(FastAPI 백엔드, Next.js 대시보드, YOLOv8 비전 클라이언트, Mock 하드웨어)이 이미 구현되어 있으므로, **본편 01·02를 따라 환경을 띄우고 동작을 확인한 뒤, 03번과 부록 문서를 활용해 2차 개발을 진행**하면 됩니다. 코드가 낯설다면 **부록E 슬라이드**로 시스템 구조부터 그림으로 훑어보세요.

> 🧰 **IoT 개발 플랫폼 키트가 적용되었습니다 (2차 개발부터).**
> 센서·액추에이터를 바꿔도 **백엔드·DB·vision은 고치지 않습니다.** 고치는 곳은 두 군데뿐입니다.
>
> | 하고 싶은 것 | 고치는 파일 |
> |---|---|
> | 부품 추가·제거·핀 변경 | `pi/slot_map.py` 한 줄 |
> | 화면·시나리오(게임·미션) | `frontend/` (`scenarios/`, `components/team/`) |
> | 반복 자동화(임계값·시각) | 코드 아님 — 대시보드 `/kit`의 규칙 편집기 |
> | 카메라 감지 대상 | 코드 아님 — 대시보드 `/kit`의 영상인식 설정 |
>
> 자세한 규약은 **부록F**를 보세요. 화면은 `/`(우리 팀 시나리오)와 `/kit`(하드웨어 구성·규칙) 둘입니다.
