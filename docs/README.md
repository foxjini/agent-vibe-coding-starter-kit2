# docs 안내 — 어떤 문서를 언제 보나요

이 폴더는 **웹 예약 연동 자동화 학교 노래방 부스 관리 시스템**의 **2차 개발(라즈베리파이 5 실기기 연동, 기능 고도화, 클라우드 배포)**을 위한 문서 모음입니다.
1차 완성을 마친 저장소(`karaoke` 브랜치)를 클론한 상태이므로, **본편 3개(01·02·03)를 중심으로 순서대로 따라가면 되며, 부록은 필요한 순간에만 펼쳐 보면 됩니다.**

## 본편 — 2차 개발 핵심 순서

| 번호 | 문서 | 주요 내용 및 활용 시점 |
|---|---|---|
| **01** | [학생용 설치 및 사용 매뉴얼](01-학생용-설치-및-사용-매뉴얼.md) | **2차 개발 전 과정 상세 가이드**.<br>- 깃허브 `karaoke` 브랜치 클론 및 로컬 가상환경(백엔드/비전)·패키지 셋업<br>- 1차 완성 시스템 로컬 구동 점검 (FastAPI, Next.js, MariaDB, 웹 대시보드, 웹캠 비전 클라이언트)<br>- 라즈베리파이 5 실기기 연동 (GPIO 배선, `pi/main.py` 데몬 구동, 백엔드 중계 모드 전환)<br>- 클라우드 배포 (Supabase, Render, Vercel) |
| **02** | [학생 수작업 로드맵](02-학생-수작업-로드맵.md) | 01을 따라가면서 **진행 상황을 체크하는 체크리스트**.<br>AI에게 시키지 않고 학생이 직접 터미널/하드웨어/웹에서 실행해야 할 작업만 집약한 실습 가이드 |
| **03** | [2차 개발 생성형 AI 핸드오버 가이드](03-2차개발-생성형AI-핸드오버-가이드.md) | **생성형 AI(ChatGPT, Claude, Cursor 등)에게 2차 개발을 인수인계**할 때 사용하는 지침서.<br>기존 1차 완성 아키텍처/API 규격 유지 요령 및 프롬프트 템플릿 포함 |

> 💡 **2차 개발 진행 요령**:
> 1. `01` 매뉴얼과 `02` 체크리스트로 환경을 셋업하고 로컬 1차 시스템을 점검합니다.
> 2. 하드웨어 담당자는 `부록A`와 `부록B`를 보며 라즈베리파이 5를 연결합니다.
> 3. 새 기능을 추가하거나 수정할 때는 `03` 핸드오버 가이드를 프롬프트에 제공하며 AI와 페어 프로그래밍합니다.
