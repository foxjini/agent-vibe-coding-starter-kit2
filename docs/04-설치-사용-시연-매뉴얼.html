한눈에 보기

전시장에서는 노트북 한 대가 백엔드·프론트엔드·DB를 모두 맡고, 같은 공유기에 붙은 기기들이 노트북의 IP 주소로 접속합니다. 인터넷이 끊겨도 부스는 그대로 돌아갑니다. 인터넷이 필요한 것은 유튜브 노래방 영상뿐이고, 영상이 막히면 내장 반주로 넘어갑니다.

1부 6단계에서 ipconfig로 확인한 주소를 넣으면, 이 문서의 명령과 설정에 들어간 주소가 모두 바뀝니다. 지금 보이는 192.168.0.25는 예시입니다.

5

프론트엔드

새 PowerShell 창 · 저장소 폴더에서 
cd frontend
npm install
copy .env.example .env

frontend\.env에 노트북 주소를 넣습니다. 혼자 노트북에서만 볼 때는 localhost로 둬도 되지만, 폰·부스 TV·라즈베리파이가 붙는 순간 IP가 필요합니다. 폰의 브라우저에게 localhost는 폰 자신이기 때문입니다.

frontend\.env 
NEXT_PUBLIC_API_BASE_URL=http://192.168.0.25:8000
NEXT_PUBLIC_WS_URL=ws://192.168.0.25:8000/ws
# 부스 화면 QR이 가리킬 주소. 비우면 부스 화면을 연 주소를 쓴다
NEXT_PUBLIC_SITE_URL=http://192.168.0.25:3000
개발할 때 
npm run dev
전시할 때 (빠르고 안정적) 
npm run build
npm start
주의

NEXT_PUBLIC_으로 시작하는 값은 빌드할 때 화면 코드에 박힙니다. 값을 바꾼 뒤에는 npm run build를 다시 해야 반영됩니다.

6

노트북을 전시장 서버로 만들기

  1. IP 확인 · ipconfig를 실행해 Wi-Fi 어댑터의 “IPv4 주소”를 찾고, 맨 위 입력칸에 넣습니다.
  2. IP 고정 · 공유기 관리 화면에서 이 노트북에 고정 IP(DHCP 고정 할당)를 줍니다. 켤 때마다 IP가 바뀌면 QR과 라즈베리파이 설정이 모두 어긋납니다.
  3. 방화벽 열기 · 관리자 권한 PowerShell에서 아래 두 줄을 실행합니다.
관리자 PowerShell 
netsh advfirewall firewall add rule name="booth-api-8000" dir=in action=allow protocol=TCP localport=8000
netsh advfirewall firewall add rule name="booth-web-3000" dir=in action=allow protocol=TCP localport=3000
  1. 절전 끄기 · 설정 → 시스템 → 전원에서 화면 끄기와 절전을 “안 함”으로 바꿉니다. 노트북이 잠들면 부스 전체가 멈춥니다.
  2. 폰으로 확인 · 폰을 같은 Wi-Fi에 붙이고 http://192.168.0.25:3000/try가 열리는지 봅니다.
7

라즈베리파이 연결

OS 설치, 가상환경, 배선, 자가진단은 부록I를 따릅니다. 여기서는 노트북과 잇는 부분만 적습니다.

라즈베리파이 · pi/.env 
BACKEND_URL=http://192.168.0.25:8000
DEVICE_API_KEY=backend\.env 와 같은 값
POLL_INTERVAL_SEC=3.0
# 도어락이 반대로 움직이면 false (Low Level Trigger 릴레이)
RELAY_ACTIVE_HIGH=true
라즈베리파이 터미널 
cd agent-vibe-coding-starter-kit2/pi
source venv/bin/activate
python main.py

노트북 쪽 backend\.env의 DEVICE_MODE를 hardware로 바꾸고 백엔드를 다시 켭니다. 전시 때는 부록I 11단계대로 부팅 자동 실행(systemd)을 걸어 둡니다.

확인

데몬 화면에 🔒 안전 상태로 초기화와 📤 보고 완료가 찍히고, 관리자 화면 운영 요약이 “지시대로 동작 중”이면 연결된 것입니다.

안전

릴레이에는 저전압(5V·12V) 기기만 연결합니다. 220V 직결은 하지 않고, 배선은 전원을 끈 상태에서 교사 입회 하에 합니다. 도어락은 실제 문이 아닌 데모 패널에 답니다 (부록G §6).

8

웹캠 입장 감지 선택

입장 감지는 라즈베리파이의 PIR 센서가 맡습니다. vision 폴더의 웹캠 클라이언트는 추가로 쓰고 싶을 때만 01 매뉴얼 1-3단계대로 켭니다.

9

설치 확인

매일 켜는 순서

  1. 공유기
  2. XAMPP의 MySQL [Start]
  3. 백엔드 uvicorn …
  4. 프론트엔드 npm start
  5. 라즈베리파이 전원 (자동 실행)
  6. 부스 TV에 /booth, F11
  7. 노트북에 /admin

끄는 순서

  1. 라즈베리파이 데몬 Ctrl+C. 도어락을 잠그고 전원을 끈 뒤 종료합니다
  2. 프론트엔드·백엔드 창에서 Ctrl+C
  3. XAMPP의 MySQL [Stop]
클라우드

Render·Vercel·Supabase에 올리는 방법은 01 매뉴얼 4단계와 부록G §7에 있습니다. 전시장에서는 이 문서의 노트북 폐쇄망 구성을 기본으로 하고, 클라우드는 백업으로 둡니다. Supabase를 쓴다면 새 코드를 받은 뒤 SQL Editor에서 init_supabase.sql을 한 번 더 실행합니다(여러 번 실행해도 안전합니다).

2부

사용

화면은 보는 사람과 기기에 따라 넷으로 나뉩니다. 학생·관람객 화면에는 도어락·전원 버튼이 아예 없고, 기기를 움직이는 조작은 모두 관리자 화면에만 있습니다.

/ 예약하고 비밀번호 받기 학교 학생 · 자기 폰

  1. 맨 위 부스 현황에서 지금 비어 있는지, 오늘 어느 시간대가 찼는지 봅니다.
  2. 학년, 학과, 신청자 이름(2자 이상), 이용 인원(최대 10명)을 넣습니다.
  3. 예약 일자를 고릅니다. 당일 예약은 안 되므로 내일부터 고를 수 있습니다.
  4. 점심 타임 12:30~13:20 또는 저녁 타임 17:30~18:30을 고릅니다.
  5. [예약 신청 및 비밀번호 발급]을 누르면 입장 비밀번호 4자리가 크게 뜹니다. 이 폰에 저장되어 페이지를 닫아도 남습니다.
  6. 이용 시간에, 시작 10분 전부터 부스 앞 키패드로 그 네 자리를 누릅니다.
규칙

같은 날 같은 시간대는 한 팀만 예약할 수 있습니다. 비밀번호는 한 번만 쓸 수 있습니다. 시작하고 15분 안에 들어오지 않으면 예약이 자동으로 취소됩니다(노쇼). 화면 아래 “기다리는 동안”에서는 노래 기록과 노래 퀴즈를 볼 수 있습니다.

/try 체험권으로 줄 서기 전시장 관람객 · 자기 폰

  1. 부스 TV나 안내판의 QR을 찍습니다.
  2. 이름을 넣고(선택, 호출할 때 부릅니다) [체험권 받기]를 누릅니다.
  3. 대기 번호, 앞에 남은 사람 수, 예상 대기 시간이 뜹니다. 페이지를 닫아도 체험권은 이 폰에 남습니다.
  4. 차례가 되면 “지금 입장하세요”와 입장 비밀번호가 뜹니다. 그 전에는 비밀번호가 보이지 않습니다.
  5. 2분 안에 부스 키패드로 누르면 문이 열리고 3분 동안 이용합니다.
알아 둘 것

2분 안에 오지 않으면 “차례를 놓쳤습니다”가 뜨고 다음 사람에게 넘어갑니다. [다시 줄 서기]로 새 체험권을 받습니다. 예약한 학생의 이용 시간에는 호출이 잠시 멈추고, 그 이유가 화면에 뜹니다.

/booth 노래하고 채점받기 부스 이용자 · 부스 TV

아무도 쓰지 않을 때는 대기 화면이 떠 있습니다. QR, “지금 호출 N번”과 이름, 대기 인원과 예상 시간, 그리고 오늘의 순위·명예의 전당·인기곡이 8초마다 번갈아 나옵니다.

  1. 순위에 올릴 이름을 넣고(선택) [노래방 시작하기]를 누릅니다.
  2. 마이크 권한을 허용하면 주변 소음을 잠깐 잽니다. “준비 완료”가 뜨면 됩니다. 마이크 없이 둘러보려면 [마이크 없이 둘러보기].
  3. 학생 애창곡 TOP 10에서 곡을 고르거나 검색합니다.
  4. [반주 시작]을 누르고 노래합니다. 음정과 성량이 실시간으로 움직입니다.
  5. 곡이 끝나면 자동으로 채점합니다. 중간에 끝내려면 [노래 완료 & 점수 채점! 💯].
  6. 점수와 등급이 뜨고 순위에 반영됩니다. [한 번 더 부르기!] 또는 [닫기].
팁

마이크가 소리를 못 잡으면 [가상보컬]로 채점을 체험할 수 있습니다. 소리를 내지 않고 채점을 누르면 점수를 지어내지 않습니다.

유튜브가 막힌 네트워크에서는 12초 안에 내장 자동 반주로 넘어갑니다. 이용이 끝나 전원이 꺼지면 15초 뒤 대기 화면으로 돌아가 다음 사람이 QR과 호출 번호를 볼 수 있습니다. 전체 화면은 F11입니다.

/admin 운영하기 선생님 · 노트북

관리자 PIN을 넣고 [인증]을 누르면 운영 화면이 나타납니다. 인증 전에는 아무것도 그려지지 않습니다. 5번 연속 틀리면 30초 동안 막힙니다. 패널은 위에서부터 이 순서입니다.

패널보는 것쓰는 버튼
운영 요약부스 상태, 기기가 지시대로 움직이는지, 오늘 예약—

전시장 상시 운영 · 관람객 한 명의 흐름

  1. 대기
    QR → 체험권대기 번호를 받고 줄을 섭니다. 차례가 다가오면 폰과 부스 TV에 “지금 호출 N번”이 뜹니다.
  2. +0:00
    호출폰에 입장 비밀번호가 뜹니다. 2분 안에 오지 않으면 다음 사람에게 넘어갑니다.
  3. +0:30
    입장키패드에 비밀번호 → 도어락·전원·조명·환영 안내. 여기서부터 3분이 셉니다.
  4. +0:45
    노래[노래방 시작하기] → 곡 선택 → [반주 시작]. 한 곡을 부르기에 충분한 시간입니다.
  5. +3:30
    종료입장 3분 뒤 전원·도어락이 정리되고 다음 사람이 호출됩니다. 엔진 주기 때문에 최대 1분 늦을 수 있습니다.
  6. +3:45
    정리부스 TV가 대기 화면으로 돌아갑니다. 안내 담당이 마이크 커버를 갈아 끼웁니다.

한 사람에 4~5분, 한 시간에 12~15명이 체험합니다. 줄이 길어지면 폰에 보이는 예상 대기 시간을 그대로 안내하면 됩니다.
