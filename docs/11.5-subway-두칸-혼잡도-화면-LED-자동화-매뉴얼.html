    11.5 subway 팀
    두 칸 혼잡도 → 화면과 LED 2개로

    웹캠 2대로 지하철 1번 칸·2번 칸의 혼잡도를 재서 ① 화면에 칸마다 보여 주고 ② 자동화 규칙으로 네오픽셀 LED 2개를 칸마다 다른 색(여유 초록 → 매우 혼잡 빨강)으로 켭니다. 브라우저를 닫아도 LED는 백엔드 규칙이 계속 바꿉니다.

    팀 subway · 지하철 혼잡도 시스템 누가 1장 비전 담당 · 2장 프론트 담당 · 3장 둘이 함께(+파이 담당) 먼저 11.4로 웹캠 2대 연동을 해 본 상태 넘기기 ← → · 목차
    이번에 키트(플랫폼)가 바뀌었습니다 — 4번 슬라이드부터

    혼잡도를 사람 수가 아니라 점유율(occupancy, %)로 잽니다 — 화면에서 사람이 차지한 넓이의 비율입니다. 사람이 겹쳐 보여 수를 잘못 세도 "얼마나 꽉 찼는지"는 덜 흔들립니다. 규칙 편집기에서 점유율 범위와 LED 색을 고릅니다. 팀 PC에서 키트를 받아야 쓸 수 있습니다.

    이미 사람 수로 만들어 둔 팀

    받아도 예전 규칙(사람 수)과 화면은 그대로 동작합니다. 점유율로 옮기는 순서: ① 4번 슬라이드로 키트 받기 ② 6번에서 창의 % 확인 ③ 8번 카드 코드 바꾸기 ④ /kit 규칙 8개를 [수정]으로 열어 "사람 수" → "점유율(%)"로 바꾸고 10번 표의 숫자 넣기.

    이 매뉴얼의 화면·규칙·로그는 실제로 실행해 확인한 것입니다 (가짜 이벤트로 1번 칸 점유율 30% → LED 노랑, 2번 칸 70% → LED 빨강).

    OVERVIEW

    한눈에 보기 — 웹캠 1대 = 칸 1개 = LED 1개

    칸웹캠 · 비전 창보내는 라벨화면 (2장)LED (3장 · 자동화 규칙)
    1번 칸웹캠 #0 · 창 ① (SUBWAY_CAR=car_1)car_1점유율(%) · 혼잡 단계 · LED 색1번 칸 LED (예: actuator_05)
    2번 칸웹캠 #1 · 창 ② (SUBWAY_CAR=car_2)car_2점유율(%) · 혼잡 단계 · LED 색2번 칸 LED (예: actuator_06)

    규칙은 웹캠이 아니라 라벨을 고릅니다

    규칙 편집기에는 "웹캠 2"라는 항목이 없습니다. 2번 웹캠 = 라벨 car_2입니다. 감지할 대상에 car_2를 고르면 2번 웹캠 규칙입니다.

    LED는 규칙만 제어

    화면 코드는 LED 색을 보여 주기만 합니다. 화면과 규칙이 같은 LED를 함께 바꾸면 서로 덮어써 깜빡입니다.

    단계는 검출기가 정함

    점유율 → 단계 기준은 vision/detectors/subway_cars.py의 OCCUPANCY_LEVELS = (20, 40, 60) (%). 규칙의 점유율 범위도 이 숫자에 맞춥니다.

    2-2. 두 칸 혼잡도 + LED 색 카드 넣기

    새 파일 frontend/components/team/CarCrowdLive.tsx
    /**
 * 두 칸 혼잡도 + LED 색 카드 (subway 팀 화면)
 * 웹캠 2대가 보내는 car_1·car_2 이벤트를 받아 칸마다 점유율(%)·혼잡 단계·사람 수를 보여 주고,
 * 자동화 규칙이 켠 LED의 지금 색도 함께 보여 줍니다. (LED는 규칙이 제어 — 여기서는 보기만)
 */
"use client";

import React, { useEffect, useState } from "react";

import { useScenario } from "@/lib/scenario";
import { asObject } from "@/lib/slots";

// ★ 우리 팀 슬롯 번호로 바꾸세요 (/kit → 하드웨어 구성)
const CARS = [
  { label: "car_1", name: "1번 칸", led: "actuator_05" },
  { label: "car_2", name: "2번 칸", led: "actuator_06" },
];
const LEVEL_NAMES = ["여유", "보통", "혼잡", "매우 혼잡"];
const STALE_MS = 10_000; // 10초 동안 소식이 없으면 "카메라 소식 없음"

interface CarReading {
  occupancy: number | null; // 점유율 % (검출기가 아직 예전 것이면 null)
  people: number;
  level: number;
  at: number;
}

export default function CarCrowdLive() {
  const { onVision, slotOf } = useScenario();
  const [cars, setCars] = useState<Record<string, CarReading>>({});
  const [now, setNow] = useState(0);

  // car_1·car_2 이벤트만 받습니다 (점유율은 extra.occupancy, 사람 수는 extra.people, 단계는 extra.level)
  useEffect(
    () =>
      onVision(
        CARS.map((car) => car.label),
        (event) => {
          const extra = asObject(event.extra) ?? {};
          const people = Number(extra.people ?? event.count ?? 0);
          const occupancy = typeof extra.occupancy === "number" ? extra.occupancy : null;
          const level = Number(extra.level ?? 0);
          const label = String(event.label ?? "");
          setCars((prev) => ({ ...prev, [label]: { occupancy, people, level, at: Date.now() } }));
        }
      ),
    [onVision]
  );

  // 1초마다 지금 시각 — "소식 없음" 판정용
  useEffect(() => {
    const timer = setInterval(() => setNow(Date.now()), 1000);
    return () => clearInterval(timer);
  }, []);

  return (
    <div className="grid grid-cols-2 gap-4">
      {CARS.map((car) => {
        const reading = cars[car.label];
        const fresh = reading !== undefined && now - reading.at < STALE_MS;
        const led = slotOf(car.led);
        const ledValue = asObject(led?.current_value ?? led?.desired_value);
        const ledOn = String(led?.current_state ?? led?.desired_state ?? "") === "on";
        const ledColor = ledOn ? String(ledValue?.color ?? "#ffffff") : "transparent";
        return (
          <section key={car.label} className="rounded-xl border border-slate-200 bg-white p-5">
            <h3 className="text-lg font-semibold text-slate-800">{car.name}</h3>
            {fresh ? (
              <>
                <p className="mt-2 text-5xl font-semibold tabular-nums text-slate-900">
                  {reading.occupancy ?? reading.people}
                  <span className="ml-1 text-xl text-slate-500">
                    {reading.occupancy === null ? "명" : "%"}
                  </span>
                </p>
                <p className="mt-1 text-lg text-slate-700">
                  {LEVEL_NAMES[reading.level] ?? "—"}
                  {reading.occupancy !== null && (
                    <span className="ml-2 text-sm text-slate-500">{reading.people}명 보임</span>
                  )}
                </p>
              </>
            ) : (
              <p className="mt-2 text-lg text-slate-500">카메라 소식 없음</p>
            )}
            <p className="mt-3 flex items-center gap-2 text-sm text-slate-600">
              <span
                aria-hidden="true"
                className="h-5 w-5 rounded-full border border-slate-300"
                style={{ backgroundColor: ledColor }}
              />
              LED {led ? (ledOn ? String(ledValue?.color ?? "켜짐") : "꺼짐") : "배치표에 없음"}
            </p>
          </section>
        );
      })}
    </div>
  );
}

    3장 · 자동화 규칙

    3-3. /kit에서 규칙 만들기 — 8번 반복

    1. /kit → 자동화 규칙 → 규칙 추가
    2. 규칙 이름표의 이름 (예: 1번 칸 보통)
    3. 언제"카메라가 무언가를 감지하면" → 감지할 대상 칩에서 car_1 (2번 칸이면 car_2). 칩이 없으면 칸에 직접 입력
    4. 범위기준을 점유율(%)로 바꾸고 20 % 이상 40 % 미만 (매우 혼잡은 미만 칸을 비움)
    5. 무엇을액추에이터 제어 → 그 칸의 LED → 켜기 → 색을 눌러 표의 색 고르기 (#ffd600 칸에 직접 입력 가능)
    6. 규칙 만들기 → 목록에 "카메라가 'car_1'을(를) 감지하면 (점유율 20~39%) → 1번 칸 혼잡도 LED을(를) on #ffd600"

    "색" 칸은 LED가 RGB·네오픽셀이고 "켜기"일 때만 보입니다. 다음 규칙은 "규칙 추가"를 다시 누르면 기본값으로 돌아가니 기준(점유율)·숫자·색을 다시 넣습니다. 이미 사람 수로 만든 규칙은 지우지 말고 [수정]으로 열어 기준과 숫자만 바꿉니다.
