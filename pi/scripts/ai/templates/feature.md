## 지켜 줄 것
- 위 파일 밖의 파일은 고치지 말 것. 꼭 필요하면 계획에서 먼저 말할 것
- 기존 동작·문구·주석은 이번 작업과 상관없으면 그대로 둘 것 (외과적 변경)
- 핀 번호는 `booth_pins.py`에만 적을 것. 이미 쓰는 핀과 겹치지 않게 할 것
- 새 액추에이터는 시작·종료 때 꺼진 안전 상태가 되게 `safe_state()`와 `close()`에 넣을 것
- 가장 단순한 방법으로. 새 pip 패키지를 쓰지 말 것. `RPi.GPIO`는 쓰지 말 것
- 백엔드에 없는 API나 기기 id가 필요하면 코드를 지어내지 말고 "백엔드 담당에게 부탁할 내용"으로 따로 적을 것
- 배선이 바뀌면 계획에 **배선표**(부품의 핀 → 라즈베리파이 물리 핀 번호와 BCM 번호)를 함께 적을 것
