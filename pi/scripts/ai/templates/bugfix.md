## 지켜 줄 것
- 먼저 **원인**을 설명할 것. 원인이 확실하지 않으면 확인할 방법(명령, 출력, 멀티미터·자가진단)을 먼저 알려 줄 것
- 원인이 코드인지, 배선인지, 설정(`.env`)인지, 백엔드인지 구분해서 말할 것. 코드가 아니면 코드를 고치지 말 것
- `.env`의 실제 값은 나에게 묻지 말 것. 어떤 두 값을 비교하면 되는지만 알려 줄 것
- 원인과 관계없는 곳은 고치지 말 것. 전체를 새로 짜지 말고 가장 작은 수정으로
- 아래 '증거'(오류 메시지, 터미널 출력, 부품이 실제로 한 일)를 그대로 근거로 삼을 것. 증거와 맞지 않는 추측으로 고치지 말 것
