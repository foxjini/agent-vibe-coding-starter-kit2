# AGENTS.md — 보이스피싱 검사 사전 테스트 앱 (Android)

> AI 에이전트가 이 프로젝트에서 **가장 먼저 읽는 파일**이다.
> 요구사항 원본은 **`docs/07_안드로이드-사전테스트앱-PRD.md`**다 — 팀 저장소에서
> 이 프로젝트의 `docs/`로 복사해 둔다. 이 파일과 규칙이 어긋나면 **PRD가 기준**이다.

## 이 앱은 무엇인가

팀의 최종 결과물은 **Flutter 앱**이다. 이 앱은 그 전에
**백엔드·ATM 연동이 실제 스마트폰에서 도는지 먼저 확인하는 검증 도구**다.

만드는 사람은 지도교사이고, 끝나면 **검증된 계약과 함정 목록을 Flutter 담당
학생에게 넘기는 것**이 최종 산출물이다.

### 이 앱이 아닌 것

- 전시회에서 관람객에게 보여줄 앱 (그건 Flutter 앱의 몫)
- 구글 플레이에 배포할 앱 (APK를 직접 설치해서 쓴다)
- 예쁜 앱 — **기본 위젯만 쓴다. 꾸미는 데 시간을 쓰지 않는다**

> 에이전트에게: 요청받지 않은 UI 개선, 애니메이션, 테마, 아키텍처 계층을
> 추가하지 마라. 이 앱의 가치는 **빨리 확인하고 버려지는 것**에 있다.

## 성공 기준 (이 네 가지가 전부다)

| # | 기준 |
|---|---|
| S1 | 실제 폰에서 로그인하고 분석 결과를 받는다 |
| S2 | 문자 공유로 받은 텍스트가 DANGER 100점으로 판정된다 |
| S3 | 통화 음성 받아쓰기 텍스트가 DANGER로 판정된다 (70점 이상) — **다른 기기에서 틀어 준 소리로** |
| S4 | **앱이 띄운 QR을 라즈베리파이가 읽고 출금이 차단된다** |

**S4가 이 앱의 존재 이유다.** S1~S3은 거기까지 가는 사다리다.

## 기술 스택 (고정 — 임의로 바꾸지 않는다)

| 항목 | 값 |
|---|---|
| 언어 | Kotlin |
| 최소 SDK | API 26 (Android 8.0) |
| UI | View + XML 레이아웃, **기본 위젯만** (Compose 도입 금지 — 학습 비용이 목적과 무관) |
| 네트워크 | `HttpURLConnection` 또는 OkHttp 중 하나. **Retrofit·Hilt·Room 쓰지 않는다** |
| QR 생성 | ZXing |
| 받아쓰기 | 안드로이드 기본 `SpeechRecognizer` (**클라우드 STT 붙이지 않는다**) |
| 아키텍처 | **없다.** Activity 3~4개면 충분하다. MVVM·Clean Architecture 도입 금지 |

## 화면 (네 개면 충분하다)

1. **설정** — 서버 주소 · 계정 · [연결 확인]
2. **입력** — 텍스트 입력란 · [받아쓰기 시작/중지] · [검사하기]
3. **결과** — 등급 · 점수 · 탐지 근거
4. **QR** — ATM 카메라가 읽을 QR (밝기 최대 · 화면 꺼짐 방지)

## 절대 규칙

1. **백엔드 API 계약을 바꾸지 않는다.** 서버는 이미 완성되어 동작 중이다.
   앱이 계약에 맞춘다 (`.agents/rules/api-contract-rules.md`)
2. **서버 주소를 코드에 박지 않는다.** 전시장에서 IP가 바뀐다
3. **권한은 `INTERNET`과 `RECORD_AUDIO` 둘뿐이다.** 더 요청하지 않는다
   (단, 받아쓰기용 `<queries>` 선언은 반드시 넣는다 — 권한이 아니다)
4. **QR에는 `session_id`만 넣는다.** 위험 상세·개인정보를 넣지 않는다
5. **실패 응답은 `{"error": {...}}`다.** `detail`을 찾지 않는다
6. **통화 중인 그 폰에서 받아쓰지 않는다.** 통화 소리는 다른 기기에서 나오게 한다

## 작업 순서

`.agents/workflows/build-order.md`를 따른다. **순서를 지킨다** —
1~4단계는 전화 기능이 전혀 필요 없고, 가장 어려운 검증(S4)을 가장 단순한
입력(붙여넣기)으로 먼저 끝내게 짜여 있다.

## 알려진 한계 (숨기지 않는다)

- **규칙 엔진은 에둘러 말하면 못 잡는다.** 대본형 문구는 100점이지만
  "통장에 있는 거 좀 빼 오셔야 될 것 같은데"는 0점이다
- **받아쓰기는 100% 정확하지 않다.** 그래서 텍스트를 손으로 고칠 수 있어야 한다
- **통화 중인 폰에서는 받아쓸 수 없다.** 안드로이드 10부터 통화가 걸려 있는 동안
  일반 앱의 마이크는 무음이다(스피커폰으로 바꿔도 같다). 그래서 통화 소리는
  **다른 기기**에서 나오게 한다 — 전시에서는 녹음된 대본을 노트북이나 다른 폰으로
  틀어 주는 것이 기본이다
