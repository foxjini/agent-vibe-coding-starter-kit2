# verify-against-prd

> "다 됐습니다"라는 말을 믿지 않고 **직접 확인하는** 절차.
> PRD 12장의 체크리스트와 같은 내용이며, 여기서는 **어떻게 확인하는가**를 적는다.

## 준비

- 백엔드가 PC에서 `--host 0.0.0.0`으로 떠 있다
- 라즈베리파이 ATM 데몬이 떠 있고 `/atm` 화면이 보인다
- 폰과 PC가 **같은 무선망**에 있다

## 확인 순서

```
□ 설정에서 서버 주소를 바꿀 수 있다
□ [연결 확인] → "연결됨"
□ 로그인 성공 → 앱을 껐다 켜도 토큰이 살아 있다

□ 보이스피싱 문자 붙여넣기 → 위험 100점, 근거 4개            (S1)
□ 일반 문자 붙여넣기 → 안전 0점, QR이 안 뜬다
□ 2000자가 넘는 글을 넣으면 앱이 먼저 알려 준다

□ 위험 결과에서 QR이 크고 밝게 뜬다
□ QR 화면에서 화면이 저절로 꺼지지 않는다
□ 그 QR을 ATM에 비춤 → 화면 빨강                            (S4)
□ 50만원을 눌러도 서보가 움직이지 않는다                      (S4 핵심)
□ 콜센터에서 해제 → ATM에서 다시 배출된다

□ 문자 앱에서 [공유] → 앱이 열리고 내용이 채워져 있다         (S2)
□ 앱을 끄지 않고 다른 문자를 또 공유해도 된다
□ 받은 내용을 손으로 고칠 수 있다

□ 녹음된 대본을 다른 기기로 틀어 받아쓰기 → 70점 이상           (S3)
□ 통화 중 침묵이 있어도 계속 받아쓴다                         ← 재시작 확인
□ [중지]를 누르면 정말 멈춘다 (마이크 아이콘이 사라진다)

□ 서버를 끈 상태에서 검사 → 현재 서버 주소가 포함된 오류 문구
□ 비밀번호를 틀리게 → 서버가 보낸 문구("아이디 또는 비밀번호가…")가 그대로 뜬다
  (뭉뚱그린 문구만 뜨면 실패 응답에서 `detail`을 찾고 있는 것이다 — `error`가 맞다)
□ 권한이 INTERNET + RECORD_AUDIO 둘뿐이다  (설정 > 앱 > 권한)
□ 매니페스트에 RecognitionService <queries>가 들어 있다
```

## 통과하지 못하는 것 (알려진 한계)

에둘러 말하면 0점이 나온다. **이건 앱의 버그가 아니라 규칙 엔진의 한계다.**

> "통장에 있는 거 좀 빼 오셔야 될 것 같은데, 누구한테 얘기하시면 안 되고요"
> → 0점 (안전)
