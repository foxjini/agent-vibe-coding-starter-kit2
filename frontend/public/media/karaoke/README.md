# 노래방 미디어 폴더 (`frontend/public/media/karaoke/`)

학생이 선곡했을 때 재생할 **반주(MR)·노래방 영상 파일**을 두는 곳입니다.

> ⚠️ **먼저 읽어야 할 문서**: [`docs/부록F-노래방-미디어-저작권-검토-및-구현계획.md`](../../../../docs/부록F-노래방-미디어-저작권-검토-및-구현계획.md)
> — 유튜브 영상을 내려받아 이 폴더에 넣는 것은 **허용되지 않습니다.** 그 이유와 대안이 문서에 정리돼 있습니다.

---

## 이 폴더에 넣어도 되는 파일

| 구분 | 예시 | 라이선스 표기 |
|------|------|----------------|
| ✅ 학교가 정식 구매·구독한 반주 음원 | TJ미디어/금영 공식 MR 상품, 유료 MR 판매 사이트 구매분 | `school-licensed` |
| ✅ 학생이 직접 만든 반주 | 밴드부 연주 녹음, MIDI/DAW로 직접 편곡한 MR | `self-produced` |
| ✅ CC 라이선스 / 퍼블릭 도메인 음원 | CC BY, CC0, 저작권 만료곡 | `cc-or-public-domain` |

## 이 폴더에 넣으면 **안 되는** 파일

| 구분 | 이유 |
|------|------|
| ❌ 유튜브에서 내려받은 영상·음원 (`yt-dlp` 등) | YouTube 서비스 약관 위반 + 저작권법상 복제권 침해 |
| ❌ 노래방 기기에서 녹음·추출한 MR | 반주 음원 제작자의 권리 침해 |
| ❌ 음원 사이트에서 받은 원곡 MP3 | 사적이용 범위를 벗어남 (부스·전시회는 "가정에 준하는 범위"가 아님) |

---

## 파일 이름 규칙

`frontend/data/karaokeSongs.ts`의 `id` 값을 그대로 파일명으로 씁니다.

```
frontend/public/media/karaoke/
├── gomin-jungdok.mp3        ← id: "gomin-jungdok"
├── one-page.mp3             ← id: "one-page"
├── event-horizon.mp4        ← 영상 파일도 가능 (가사 화면이 들어있는 경우)
└── ...
```

지원 확장자: `.mp3` `.m4a` `.wav` `.ogg` (오디오) / `.mp4` `.webm` (영상)

파일을 넣으면 앱이 시작할 때 자동으로 감지해서 **로컬 파일을 1순위로 재생**합니다.
(재생 우선순위: 로컬 파일 → 유튜브 공식 임베드 → 내장 신스 자동 반주)

---

## 파일을 넣은 뒤 할 일

1. `LICENSE-LEDGER.md`에 **어디서 받았는지 / 어떤 권리로 쓰는지** 한 줄 기록
2. `frontend/data/karaokeSongs.ts`에서 해당 곡의 `license` 값을 실제 근거로 수정
3. `npm run dev`로 실행해서 소리가 나는지 **직접 귀로 확인** (AGENTS.md의 AI 사용 원칙)

파일 자체는 `.gitignore`에 걸려 있어 커밋되지 않습니다. 전시회 노트북에는
저장소를 클론한 뒤 이 폴더에 파일을 **직접 복사**해서 쓰세요.
