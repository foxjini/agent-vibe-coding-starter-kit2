# wakeup 디자인 시스템 — "새벽빛"

7인치 터치모니터(800×480, 가로)에 띄우는 `/wakeup` 화면의 디자인 규칙입니다.
**wakeup 팀 화면에만 적용**되며, 다른 3팀 화면과 공통 코드(`lib/`, `components/kit/`)는 이 규칙과 관계없습니다.

- 토큰(색·크기): `frontend/app/wakeup/wakeup.css` — 모든 규칙이 `.wk` 안에 있습니다
- 글꼴: `frontend/app/wakeup/layout.tsx` — IBM Plex Sans KR (build 때 PC가 받아 함께 내보냄)
- 기본 조각: `components/team/wakeup/Tile.tsx` — `Panel`, `TouchButton`, `State`, `MissingSlot`

## 1. 생각

침실 머리맡에 놓이는 화면입니다. 사용자는 대부분 **반쯤 잠든 상태**로 이 화면을 봅니다.

| 상태 | 언제 | 화면이 할 일 |
|---|---|---|
| **night** (밤) | 평상시 | 눈부시지 않게. 시각과 다음 알람만 조용히 |
| **dawn** (새벽) | 알람·기상 미션 중, 기상 확인 창 | 화면 전체가 해 뜨는 색이 되어 조명(네오픽셀)과 함께 깨움. 해야 할 일 하나를 가장 크게 |

**큰 연출은 단 하나** — 알람이 울릴 때 화면 아래에서 해가 떠오르는 빛(`.wk-sunrise`). 그 밖의 곳은 조용하게 둡니다.

## 2. 색

컴포넌트는 원색(hex)을 직접 쓰지 않고 **의미 변수**만 씁니다. 그래서 `data-phase`가 바뀌면 화면 전체 색이 함께 바뀝니다.

| 의미 변수 | night | dawn | 쓰는 곳 |
|---|---|---|---|
| `--wk-bg` | `#0f1226` 깊은 남색 | `#fff1df` 새벽 하늘 | 화면 바탕 |
| `--wk-raised` | `#171b36` | 반투명 흰빛 | 묶음(`Panel`) 바탕 |
| `--wk-sunken` | `#0b0d1d` | 반투명 살구 | 막대그래프 바닥 |
| `--wk-line` / `--wk-line-strong` | `#232850` / `#343a6b` | 흙색 18% / 32% | 구분선 / 버튼 테두리 |
| `--wk-text` | `#e6e3f4` 달빛 | `#3b1d10` 짙은 흙색 | 본문 |
| `--wk-dim` | `#a3a7cc` | `#6b3a22` | 보조 글자 |
| `--wk-accent` | `#f5a85b` 앰버(램프 색) | `#3b1d10` | 화면마다 **주된 행동 하나**, 지금 탭 |
| `--wk-on-accent` | `#2a1606` | `#fff1df` | accent 위 글자 |
| `--wk-ok` | `#86dcb6` | `#1f6b4a` | 켜짐·완료 |
| `--wk-alert` | `#ff8f80` | `#a3321f` | 오류·연결 끊김 |

- 모든 글자는 바탕 대비 **4.5:1 이상**입니다 (UI UX Pro Max 점검 기준). 새 색을 넣으면 꼭 다시 잽니다.
- 앰버는 조명 네오픽셀의 기상 색(`#ffb45a`)과 같은 계열입니다. 화면과 방의 빛이 같은 이야기를 합니다.
- Tailwind에서 쓰는 법: `bg-(--wk-raised)`, `text-(--wk-dim)`, `border-(--wk-line)`

## 3. 글자

글꼴은 **IBM Plex Sans KR 하나**입니다. 굵기로 위계를 만듭니다.

| 역할 | 크기 | 굵기 | 예 |
|---|---|---|---|
| 큰 시계 | 136px | `--wk-clock-weight` (밤 200 · 새벽 600) | 홈 시계 |
| 미션 지시 | 56px | 600 | "가위를 내세요" |
| 큰 값 | 44~88px | 500 또는 `.wk-clock` | 다음 알람, 예약 시각, 압력 |
| 제목·줄 이름 | 18px (`text-lg`) | 500 | "침대 압력", "커튼" |
| 본문·버튼 | 16px (`text-base`) | 400 | 상태, 설명 |
| 최소 | 14px (`text-sm`) | 400 | 연결 상태, 보조 안내 — 이보다 작게 쓰지 않습니다 |

- **밤에는 가는 숫자**: 획이 가늘면 빛을 덜 내서 어두운 방에서 덜 눈부십니다. 새벽에는 굵게 바꿔 잠을 깨웁니다.
- 숫자는 폭이 일정한 숫자(`tnum`)를 씁니다 — 시계가 바뀔 때 흔들리지 않습니다.

## 4. 크기·간격

| 항목 | 값 |
|---|---|
| 터치 영역 | 최소 **48px**(`min-h-12`), 주된 버튼 56~64px |
| 버튼 사이 | 8px(`gap-2`) 이상 |
| 화면 여백 | 좌우 20~32px |
| 모서리 | 버튼 12px(`--wk-radius-control`), 묶음 20px(`--wk-radius-panel`), 점·막대는 완전히 둥글게 |
| 고정 높이 | 상단 줄 48px · 알림 줄 44px · 하단 탭 60px |

## 5. 조각과 쓰는 법

- `TouchButton` tone
  - `plain` 보통 · `selected` 지금 고른 값(`ariaPressed`와 함께) · `quiet` 글자만
  - `accent` **그 화면의 주된 행동 하나에만** (예약 화면 "맞추기", 미션 화면 "알람 끄기", 기상 확인 "일어났어요")
- `State` — 켜짐/꺼짐 같은 짧은 상태. 색만이 아니라 **점 모양(채움/빈 원)과 글자**로도 구분합니다.
- `Panel` — 정말 한 묶음일 때만. 같은 모양 상자를 줄줄이 늘어놓지 않고, 목록은 줄(구분선)로 만듭니다.
- 눌렀을 때 반응은 `wk-press`(살짝 작아짐)와 `active:bg-(--wk-press)`. 터치 화면에는 hover가 없습니다.

## 6. 말투

- 사용자 입장의 쉬운 말, 존댓말 "~요": "침대에 누워 있어요", "알람이 없어요"
- 버튼은 **누르면 일어나는 일**을 그대로: "07:30에 맞추기", "예약 지우기", "미션 없이 알람 끄기"
- 같은 일은 같은 이름으로. 오류는 사과하지 않고, 무엇이 문제이고 어떻게 고치는지 씁니다.

## 7. 하지 않는 것 (AI가 만든 티가 나는 것)

- 모든 내용을 똑같은 둥근 카드 + 회색 그림자로 나누기
- 모두 대문자 영어 라벨, 제목 위 작은 라벨 남발, "A · B · C"처럼 가운뎃점으로 이어 붙인 정보
- 버튼 글자 끝에 화살표(→), 이모지 아이콘(⏰ 등) — 아이콘은 lucide SVG만
- 화면마다 흩어진 등장 애니메이션 — 움직임은 해 뜨는 빛 하나와 누름 반응만
- 원색 hex를 컴포넌트에 직접 쓰기 — 의미 변수를 씁니다

## 8. 접근성 점검표 (고친 뒤 확인)

- [ ] 글자 대비 4.5:1 이상 (night·dawn 둘 다)
- [ ] 터치 영역 44px 이상, 버튼 사이 8px 이상
- [ ] 아이콘만 있는 버튼에 `aria-label`
- [ ] 움직임 줄이기 설정(`prefers-reduced-motion`)에서 해 뜨는 빛·누름 효과가 멈춤
- [ ] 800×480에서 바깥 스크롤·가로 넘침 없음
